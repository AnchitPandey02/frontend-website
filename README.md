# Modern Frontend Website

Welcome to your new frontend web project!

## 📁 Project Structure

```text
frontend-website/
├── index.html        # Main HTML structure
├── styles.css        # Responsive styling with light/dark theme variables
├── script.js         # Interactive JavaScript logic & state
└── README.md         # Project documentation
```

## 🚀 How to Run Locally

You can open `index.html` directly in your web browser:
- Double-click `index.html` in your file explorer, or
- Right click `index.html` in your editor and select "Open with Live Server" or "Open in Default Browser".

## 🐙 Connecting to GitHub

1. Set your Git identity (if you haven't already):
   ```powershell
   git config --global user.name "Your Name"
   git config --global user.email "your_email@example.com"
   ```

2. Initialize Git and make your first commit:
   ```powershell
   cd frontend-website
   git init
   git add .
   git commit -m "Initial frontend project commit"
   ```

3. Create a new repository on [GitHub](https://github.com/new) and link it:
   ```powershell
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
   *Your browser will open automatically to sign into GitHub via Git Credential Manager.*
