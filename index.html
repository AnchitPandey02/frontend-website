Backend Connection Guide

How to expose your Python AI/ML models so this frontend website can communicate with them.

Option 1 • Recommended

FastAPI Python Backend (Async & Fast)

FastAPI with CORSMiddleware makes connecting any PyTorch, Hugging Face, or scikit-learn model effortless.

# 1. Install dependencies:
# pip install fastapi uvicorn pydantic

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel

app = FastAPI(title="My AI Model API")

# Enable CORS for the frontend website
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"], # Or your specific frontend URL
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

class ChatRequest(BaseModel):
    prompt: str
    temperature: float = 0.7

@app.get("/health")
def health_check():
    return {"status": "online", "model": "ready"}

@app.post("/api/chat")
def chat_endpoint(req: ChatRequest):
    # Call your PyTorch / Transformers / Ollama model here!
    ai_response = f"Model received: '{req.prompt}'. Response generated."
    return {"reply": ai_response, "tokens": 42}

# Run with: uvicorn backend_example:app --reload --port 8000
Option 2

Flask Python Backend

Using classic Flask? Just add flask-cors to enable cross-origin requests from this web frontend.

# 1. Install dependencies:
# pip install flask flask-cors

from flask import Flask, request, jsonify
from flask_cors import CORS

app = Flask(__name__)
CORS(app)  # Enable CORS for all domains

@app.route('/health', methods=['GET'])
def health():
    return jsonify({"status": "online"})

@app.route('/api/chat', methods=['POST'])
def chat():
    data = request.json or {}
    user_prompt = data.get('prompt', '')
    
    # Run your ML prediction logic
    return jsonify({
        "reply": f"Flask AI Response to: {user_prompt}",
        "confidence": 0.98
    })

if __name__ == '__main__':
    app.run(port=8000, debug=True)
Option 3

Ollama & LM Studio (Local LLMs)

Run open-source weights (Llama 3, Mistral, DeepSeek, Gemma, Qwen) on your GPU with zero Python code needed!

# 1. Start Ollama with CORS allowed:
# PowerShell:
$env:OLLAMA_ORIGINS="*"
ollama serve

# 2. In another terminal, pull any model:
ollama pull llama3
# (or mistral, phi3, deepseek-coder, etc.)

# 3. In NeuroHub Top Bar:
# Set Base URL: http://localhost:11434
# Set Route in NLP Playground: /api/generate
# Payload will route directly to Ollama!

💡 Top Tips for Connecting Your AI Models:

  • CORS (Cross-Origin Resource Sharing): Web browsers block cross-origin calls by default unless your backend includes the Access-Control-Allow-Origin header. Both code examples above already include CORS!
  • Localhost vs IP: If testing from mobile or another device, change http://localhost:8000 in the top bar to your machine's local IP (e.g., http://192.168.1.100:8000).
  • Demo Simulation Mode: Leave the "Demo Simulation" toggle checked while tweaking your UI, then flip it off when your Python script is running!
